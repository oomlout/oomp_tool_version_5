# M7 spanner

[Tool catalogue](../../README.md) / [wrench](../../navigation_oomp/tool/wrench/README.md)

`tool_wrench_m7`

**External tool reference.** Generic 7 mm open-end spanner using the FACOM 34.7 as a dimensional reference. Length, maximum head width and thickness follow the catalogue. The square-on jaws and shank are simplified, and the workshop specimen has not been measured.
