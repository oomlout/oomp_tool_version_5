# Four workshop tools for Blender reference

19 November 2026 · Identification report for approval

The subsequent individual photos and model measurements are available in the [modelling report](PHOTO_MODELS.md). The new knife photograph confirms the STANLEY moulding. The exact model number remains provisional.

Rapid Electronics’ 2019 catalogue pictures close matches for the red cutters and stripper on printed page 205 and the blue pliers on page 206. All three have product listings that distinguish the model number from Rapid’s order code. The craft knife has a close STANLEY family match with two blade-width variants. These are visual identifications. The workshop photograph contains no scale or readable part number. ## Decision for the first renders

The three Rapid catalogue photographs are close enough to use as shape references. Use the workshop photo for the actual handle colours and open poses. Keep branding provisional until a stamp or moulding is readable. For the knife, use the 18 mm STANLEY as the reference candidate and show the blade retracted as pictured. [Rapid catalogue](https://static.rapidonline.com/downloads/2019-edu/dt-hand-tools.pdf#page=3) · [STANLEY 18 mm](https://www.stanleytools.co.uk/en-gb/product/0-10-151/18mm-slide-lock-snap-knife) · [STANLEY 9 mm](https://www.stanleytools.co.uk/en-gb/product/0-10-150/9mm-slide-lock-snap-knife)

Two checks would most improve scale accuracy. Measure the stripper closed from tip to grip end to resolve **120 versus 130 mm**, and check the knife’s refill width or moulded model code to resolve **18 versus 9 mm**. The linked part notes include search terms, product photographs and the features worth carrying into the renders.
